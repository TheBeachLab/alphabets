# Mechanical marking font

`3270NerdFontMono-ALPHABETS.ttf` is a glyph-subset of
`3270NerdFontMono-Regular.ttf` from the official Nerd Fonts 3.5.1 `3270.zip`
release:

https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1

The source archive SHA-256 is
`6edb49851fbcc34326188529f36735913df40ab79784e00ab89db3aaa2e6ecbd`.
The subset retains only the glyphs required by the enclosure's `ALPHABETS`
mark and has SHA-256
`74ef29558aca5d95c92eb4a9eb26e2167afecdae10dd0f4d2a6ddcc63a86b350`.
The upstream license is preserved in `LICENSE-3270-NERD-FONT.txt`.

This family matches the `3270Medium Nerd Font Mono` family recorded on the
original `ALPHABETS` text element in the repository's `panel.svg`.
