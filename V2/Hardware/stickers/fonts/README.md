# Sticker typefaces

The V1 build notes identify **Blue Highway Bold**, by Raymond Larabie, as the
typeface chosen to approximate the original Solari lettering. Existing V2 SVG
files contain only converted vector paths, not reusable font files.

The sticker generator defaults to `Blue Highway D.otf`, the Blue Highway
variant used by most of the surviving V2 artwork. It uses
`Dream Orphans Bd.otf` only for `ẞ`, which is absent from the current Blue
Highway files. `Blue Highway Bd.otf` is retained as the documented V1 choice
and can be selected explicitly with `--font`.

All three files came from Typodermic's official public-domain archive and are
released under CC0 1.0. See [LICENSE-CC0.txt](LICENSE-CC0.txt).
