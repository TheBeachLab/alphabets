# Archived sticker sheets

These files are retained for traceability only. They are not manufacturing
inputs for either V2 physical variant.

- `transitional-50x86/`: the discarded narrow-but-short experiment. It matches
  neither the 55 mm prototype card nor the 50 mm definitive card.
- `experimental-international-55x86/`: an International 64 test sheet at the
  old 55 × 86 mm size. It does not match the installed Demo 64 prototype drum.

Use the variant-locked generator commands in
[`../../../variants/`](../../../variants/README.md) instead.
